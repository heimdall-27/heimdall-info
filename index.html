Heimdall

Heimdall — разрабатываемое приложение для резервного копирования рабочего окружения Linux-пользователя на Google Диск. Оно предназначено для внутреннего использования небольшой командой.

Первая версия создаёт архив домашнего каталога пользователя и загружает его в выбранную папку Google Диска. Архив включает файлы проектов, конфигурацию и сведения об окружении. Восстановление проектов на другом сервере запланировано следующим этапом.

Резервное копирование запускается вручную или по расписанию. Для передачи файлов используется rclone с доступом через Google Drive API.

При подключении владелец Google-аккаунта подтверждает разрешения в окне Google. Приложение использует полученный доступ для работы с резервными копиями.

Исходный код и готовые сборки распространяются среди участников команды через закрытые хранилища.

Подробнее об обработке данных — в политике конфиденциальности.
